# MyDiary

MyDiary 是一款使用 Electron 构建的本地日记桌面应用。日记在应用中编辑、浏览和统计；数据保存在本机的加密数据仓中。

## 使用应用

普通用户请运行安装包并从开始菜单或桌面快捷方式打开 MyDiary。Windows 安装包位于项目的 `release/` 目录。

首次启动的默认隐私门密码是 **1234**。进入应用后，请在右上角「设置」中修改密码并设置辅助验证答案。新密码为 6 位数字；首次设定后会出现提醒，需完成三次确认才能关闭。

## 功能

- 按日创建和编辑日记，支持 Markdown、图片、粘贴和拖入图片。
- 通过热力图和列表浏览日记，并查看连续记录、累计字数等统计。
- 在阅读视图查看日记；也可将日记临时导出到已配置的本地编辑器中打开。
- 将数据保存在本地加密数据仓，不需要账号。
- 可选的隐私门、密码修改和辅助验证密码重置流程。
- 隐私门开启时，最小化或关闭窗口会重新锁定；从任务栏或系统托盘打开时需再次输入密码。
- 应用窗口关闭后可驻留系统托盘，从托盘菜单重新显示或退出。

## 开发与构建

需要安装 Node.js 和 npm。在项目根目录执行：

```bash
npm install
npm run electron
```

`npm run electron` 会先通过 Vite 构建界面，再启动 Electron 桌面应用。仅运行 `npm run build` 会构建界面，不会启动桌面窗口。

构建 Windows 安装包：

```bash
npm run dist:win
```

安装包和免安装版本输出到 `release/`。当前构建目标是 Windows x64。

## 数据与隐私

- Electron 运行时的数据目录位于系统用户数据目录下的 `data/` 子目录。Windows 默认路径为 `%APPDATA%\\my-diary\\data\\`。
- 首次安装时「编辑器路径」为空。可以在设置页选择 Typora、Obsidian、VS Code 等外部编辑器；不配置时仍可在应用内编辑日记。
- 日记、图片和配置以加密文件保存在数据目录中。日记文件使用 `.enc` 扩展名，采用 AES-256-GCM 加密。
- 主密钥由 Electron 的 `safeStorage` 使用操作系统凭据保护，并保存为 `key.oscrypt`。请备份完整数据目录，尤其要同时保留密文文件和密钥文件。
- 使用外部编辑器时，应用会将日记导出为系统临时目录 `MyDiary-edit/` 下的 Markdown 文件供编辑，并监视文件变化后将内容加密写回数据仓。该临时文件是明文，应用不会自动删除；编辑结束后请自行删除，并留意系统临时目录和备份软件的处理方式。
- 应用会请求 Timor 节假日接口获取节假日信息；日记内容不会因此上传。

### 隐私门密码的保护范围

隐私门密码用于限制进入应用界面，不是日记加密密钥，也不用于派生主密钥。开启隐私门可以防止他人直接打开应用查看日记，但不能防止有权访问当前系统账户、运行中应用或本地服务的用户绕过界面锁访问数据。

忘记密码时，可在隐私门选择「忘记密码」，回答设置中的辅助验证问题后重置密码。辅助验证答案应避免使用容易被猜中或公开的信息。密码重置只更改隐私门密码，不会重新加密日记。

### 迁移与备份

在设置页的「数据迁移」中可以导出或导入 `.mydiary` 文件。导出时设置独立的迁移密码（至少 8 个字符），到新设备选择该文件并输入同一密码即可导入全部日记和图片。迁移文件使用 AES-256-GCM 加密，可跨设备迁移；请妥善保存迁移密码。

导入会替换当前设备上的全部日记和图片，应用设置、隐私门密码和本机加密密钥会保留。导入前建议先导出当前数据作为备份。迁移包不包含外部编辑器设置。

也可在同一系统账户下退出应用后，备份完整的 `data/` 目录。目录中的 `key.oscrypt` 受操作系统凭据保护，直接复制到另一台电脑或另一个系统账户后可能无法解密；跨设备迁移请使用 `.mydiary` 文件。

## 项目结构

```text
MyDiary/
├── electron/       Electron 主进程、窗口和系统托盘
├── server/         本地 API、加密存储和数据迁移
├── src/            React + TypeScript 应用界面
├── public/         前端静态资源
├── tools/          项目辅助脚本
└── package.json    启动和构建命令
```

Electron 启动时会托管本地服务，再由桌面窗口连接本机地址。开发界面由 Vite 构建；发布版使用同一套构建产物。

## 旧数据迁移

启动时，应用会尝试将项目根目录中的旧版 `diaries/*.md` 和 `config.json` 导入加密数据仓。导入成功后，旧文件不会自动删除；确认新数据完整后，可自行归档或删除旧文件。

## 技术栈

- Electron 33
- React 18、TypeScript、Tailwind CSS
- Vite 5
- Node.js、Express
- AES-256-GCM 本地文件加密
